# Fake News Detection System

## Project Description

A Java Swing based Fake News Detection System that analyzes news content and classifies it as Fake, Suspicious, or Possibly Real.

## Features

- User Login System
- Fake News Detection
- Suspicious News Detection
- News History
- Statistics Dashboard
- Clear News Input
- About Project
- Logout

## Technologies Used

- Java
- Java Swing
- CSV Dataset
- VS Code
- GitHub

## Project Files

- `Login.java` - Login screen
- `FakeNewsGUI.java` - Main GUI application
- `FakeNewsDetector.java` - News detection logic
- `news_data.csv` - Sample news dataset

## How to Run

Compile the Java files:

```bash
javac Login.java FakeNewsGUI.java FakeNewsDetector.java
